CARA MENJALANKAN DI XAMPP
─────────────────────────────────────────────────────────────
1. Copy folder "UANGKU" ke:  C:\xampp\htdocs\uangku\

2. XAMPP Control Panel → Start: Apache & MySQL

3. Import database (SEKALI saja):
   • Buka http://localhost/phpmyadmin
   • Tab "Import" → pilih file: database.sql → "Go"
   (database.sql sudah mencakup SEMUA tabel termasuk login)

   *Jika dulu sudah pakai versi lama, import berurutan:
      migrasi_v2.sql → migrasi_v3.sql → migrasi_v4.sql
   (migrasi_v4 = tiap akun punya data sendiri / multi-user)

LOGIN DENGAN GOOGLE (opsional)
─────────────────────────────────────────────────────────────
1. Buka https://console.cloud.google.com/apis/credentials
2. Create Credentials → OAuth client ID → Web application
3. Authorized redirect URI:
      http://localhost/uangku/google_callback.php
4. Salin Client ID & Client Secret ke file:
      inc/google_config.php
5. Tombol "Masuk dengan Google" otomatis aktif.

4. Buka:  http://localhost/uangku/

5. LOGIN dengan akun demo:
   Email    : budi@email.com
   Password : uangku123
   (atau klik "Daftar" untuk buat akun baru)


INSTALL DI HP (PWA)
─────────────────────────────────────────────────────────────
1. HP & komputer di WiFi sama
2. Cek IP komputer: CMD → "ipconfig" → lihat IPv4 (mis. 192.168.1.10)
3. Di HP buka Chrome: http://192.168.1.10/uangku/
4. Menu ⋮ → "Tambahkan ke Layar Utama"
